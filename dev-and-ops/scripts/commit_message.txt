feat: Update LLM integration for single-language model

This commit updates the LLM integration code to support the new single-language model
for job data. The changes include:

1. Updated extract_job_data method to handle both legacy multilingual format and new
   single-language format, with automatic conversion from the former to the latter.

2. Completely refactored normalize_job_data method to:
   - Convert multilingual data to single-language format
   - Ensure all fields follow the new schema
   - Add language and summary fields
   - Handle location data properly

3. Updated validate_schema method to validate against the new schema:
   - Added validation for language field
   - Updated validation for title, description, and requirements
   - Added validation for summary field
   - Made validation more robust with better type checking

4. Updated JobValidator class to handle both legacy and new formats:
   - Added support for language field
   - Updated validation logic for all fields
   - Improved error messages

These changes ensure that the LLM integration works seamlessly with the new
single-language model while maintaining backward compatibility with existing code.
The validation is now more robust and provides better error messages for debugging.
