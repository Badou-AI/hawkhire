# Full Stack Developer

We are seeking a skilled Full Stack Developer to join our dynamic team. The ideal candidate will have experience building scalable web applications using modern technologies and best practices.

- Design and implement new features for our web applications
- Write clean, maintainable, and efficient code

- Optimize applications for maximum speed and scalability

- 3+ years experience with React.js and Next.js

- Experience with cloud services (AWS/GCP/Azure)
- Knowledge of modern authorization mechanisms (OAuth, JWT)

## Preferred Qualifications

- Knowledge of CI/CD pipelines
- Familiarity with microservices architecture
- Experience with real-time data processing
- Understanding of SEO principles
